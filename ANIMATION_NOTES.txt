### FLOATING MENU DRAG SYSTEM (FloatingMenu.jsx)

The floating menu can be dragged around the screen using Framer Motion's drag API.

```jsx
<motion.div 
  className="fixed bottom-6 right-6 z-50"
  drag                    // Enables dragging in all directions
  dragMomentum={false}    // Disables momentum after drag ends
  dragElastic={0.1}       // Small elastic bounce when hitting constraints
  dragConstraints={{      // Defines boundaries for dragging
    left: -window.innerWidth + 100,   // Can't go beyond left edge (with 100px margin)
    right: 0,                         // Can't go beyond right edge
    top: -window.innerHeight + 100,   // Can't go beyond top edge (with 100px margin)
    bottom: 0                         // Can't go beyond bottom edge
  }}
  style={{ x: position.x, y: position.y }}  // Current position state
  onDragEnd={(event, info) => {              // Callback when drag ends
    setPosition({ x: info.offset.x, y: info.offset.y });  // Save new position
  }}
>
```

**How it works:**
- `drag` prop enables dragging functionality
- `dragConstraints` prevents the menu from being dragged off-screen
- `dragMomentum={false}` stops the element immediately when user stops dragging
- `dragElastic={0.1}` adds a small bounce effect when hitting boundaries
- `onDragEnd` saves the final position so the menu stays where user dropped it

**Position Tracking:**
```jsx
const [position, setPosition] = useState({ x: 0, y: 0 });
```
- Tracks the current X and Y offset from the original position
- Updated every time the user finishes dragging

### PAGE TRANSITION SYSTEM (PageTransition.jsx)

Smooth transitions between different pages/routes in the app.

```jsx
const pageVariants = {
  initial: {
    opacity: 0,      // Start invisible
    y: 20,           // Start 20px below final position
    scale: 0.98      // Start slightly smaller
  },
  in: {
    opacity: 1,      // Fade to fully visible
    y: 0,            // Move to final position
    scale: 1         // Scale to normal size
  },
  out: {
    opacity: 0,      // Fade out
    y: -20,          // Move 20px above final position
    scale: 1.02      // Scale slightly larger
  }
};
```

**Animation Flow:**
1. **Page Enter:** Starts invisible, below, and smaller → Fades in, moves up, scales to normal
2. **Page Exit:** Fades out, moves up, scales slightly larger

```jsx
<AnimatePresence mode="wait">  {/* Wait for exit animation before entering new page */}
  <motion.div
    key={location.pathname}      // Unique key for each route
    initial="initial"            // Start with 'initial' variant
    animate="in"                 // Animate to 'in' variant
    exit="out"                   // Exit with 'out' variant
    variants={pageVariants}      // Use the variants defined above
    transition={pageTransition}  // Custom transition timing
  >
```

**Transition Timing:**
```jsx
const pageTransition = {
  type: 'tween',        // Use tween animation (smooth)
  ease: 'anticipate',   // Easing function (starts slow, speeds up, slows down)
  duration: 0.4         // Animation takes 0.4 seconds
};
```

### ANIMATED CARDS (AnimatedCard.jsx)

Reusable card component with entrance and hover animations.

**Entrance Animation:**
```jsx
const directionVariants = {
  up: { y: 20, opacity: 0 },      // Enter from below
  down: { y: -20, opacity: 0 },   // Enter from above
  left: { x: -20, opacity: 0 },   // Enter from left
  right: { x: 20, opacity: 0 },   // Enter from right
  scale: { scale: 0.9, opacity: 0 } // Enter by scaling up
};

<motion.div
  initial={directionVariants[direction]}  // Start position based on direction prop
  animate={{ y: 0, x: 0, scale: 1, opacity: 1 }}  // End at normal position
  transition={{
    duration: 0.5,        // Animation takes 0.5 seconds
    delay: delay * 0.1,   // Stagger animation based on delay prop
    ease: "easeOut"       // Smooth deceleration
  }}
>
```

**Hover Animation:**
```jsx
const hoverVariants = {
  scale: hover ? 1.02 : 1,  // Slightly larger on hover
  y: hover ? -2 : 0,        // Lift up 2px on hover
  transition: { duration: 0.2 }  // Quick transition
};

whileHover={hover ? hoverVariants : {}}  // Apply hover effect if enabled
```

**Hover Overlay Effect:**
```jsx
{hover && isHovered && (
  <motion.div
    initial={{ opacity: 0 }}     // Start invisible
    animate={{ opacity: 1 }}     // Fade in
    exit={{ opacity: 0 }}        // Fade out
    className="absolute inset-0 bg-gradient-to-r from-blue-500/5 to-purple-500/5"
  />
)}
```


### FLOATING MENU RADIAL EXPANSION (FloatingMenu.jsx)

Menu items expand in a circular pattern around the main button.

**Radial Positioning:**
```jsx
{menuItems.map((item, index) => {
  const angle = (index * 45) + 135;  // Calculate angle for each item (45° apart, starting at 135°)
  const radius = 60;                 // Distance from center
  const x = Math.cos((angle * Math.PI) / 180) * radius;  // Calculate X position
  const y = Math.sin((angle * Math.PI) / 180) * radius;  // Calculate Y position

  return (
    <motion.button
      initial={{ scale: 0, x: 0, y: 0 }}    // Start at center, invisible
      animate={{ 
        scale: 1,                            // Grow to full size
        x: x,                                // Move to calculated X position
        y: y                                 // Move to calculated Y position
      }}
      exit={{ scale: 0, x: 0, y: 0 }}       // Shrink back to center
      transition={{ 
        delay: index * 0.1,                  // Stagger each item
        type: "spring",                      // Spring animation
        stiffness: 300,                      // How bouncy
        damping: 20                          // How much oscillation
      }}
    >
```

**Mathematical Explanation:**
- `angle = (index * 45) + 135` creates angles: 135°, 180°, 225°, 270° (top-left arc)
- `Math.cos(angle)` and `Math.sin(angle)` convert polar coordinates to X,Y coordinates
- `radius = 60` sets how far items spread from the center

================================================================================
                            5. ANIMATION BEST PRACTICES
================================================================================

### PERFORMANCE OPTIMIZATIONS

1. **Use transform properties** (scale, rotate, translate) instead of changing layout properties
2. **Limit simultaneous animations** to avoid performance issues
3. **Use AnimatePresence** for enter/exit animations
4. **Stagger animations** to create smooth, sequential effects

### ACCESSIBILITY CONSIDERATIONS

1. **Respect user preferences:**
```jsx
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
// Disable or reduce animations if user prefers reduced motion
```

2. **Provide alternative interactions** for users who can't use drag gestures

### ANIMATION TIMING

- **Quick interactions:** 0.1-0.2 seconds (button hover, tap)
- **UI transitions:** 0.3-0.5 seconds (page transitions, modal open/close)
- **Loading animations:** 1-2 seconds per cycle (skeleton loading, spinners)
- **Attention-grabbing:** 0.5-1 second (notifications, success states)

### EASING FUNCTIONS

- **easeOut:** Good for entrances (starts fast, slows down)
- **easeIn:** Good for exits (starts slow, speeds up)
- **easeInOut:** Good for continuous animations (smooth acceleration/deceleration)
- **linear:** Good for loading bars and continuous rotations
- **spring:** Good for playful, bouncy interactions

================================================================================
                            6. FRAMER MOTION CONCEPTS
================================================================================

### KEY CONCEPTS USED IN THE APP

1. **Variants:** Predefined animation states
```jsx
const variants = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0 }
};
```

2. **AnimatePresence:** Handles enter/exit animations
```jsx
<AnimatePresence mode="wait">
  {condition && <motion.div exit={{ opacity: 0 }} />}
</AnimatePresence>
```

3. **Drag:** Built-in drag functionality
```jsx
<motion.div drag dragConstraints={{ left: 0, right: 100 }} />
```

4. **Gestures:** whileHover, whileTap, whileDrag
```jsx
<motion.div whileHover={{ scale: 1.1 }} whileTap={{ scale: 0.9 }} />
```

5. **Layout animations:** Automatic layout change animations
```jsx
<motion.div layout />  // Animates position/size changes automatically
```

### COMMON PATTERNS

1. **Staggered animations:**
```jsx
transition={{ delay: index * 0.1 }}
```

2. **Conditional animations:**
```jsx
animate={isVisible ? "visible" : "hidden"}
```

3. **Chained animations:**
```jsx
transition={{ delay: 0.2, duration: 0.3 }}
```
